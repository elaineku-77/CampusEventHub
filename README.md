## Member 2 — Event Browsing & Event Details

### Features

- View all latest events (Done)
- Search events by keyword or category (Done)
- View full event details (Done)
- Check event availability based on registered participants and maximum participants (Backend)

### Remarks

- Event homepage UI is designed to be user-friendly, simple, and consistent.
- The homepage displays only the latest published events.
- Users can search for events by event name or keyword.
- The event details page displays important event information, including:
  - Event title and date
  - Category
  - Event description
  - Seats left / availability
- Event availability is calculated based on:
  - Event status
  - Total seats
  - Current registration count
- If an event is full, users can still view the event details, but registration is not allowed.
- The layout is kept simple and consistent with the overall system design.
